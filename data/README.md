# Data

All fault events are generated by the project's physics simulator (`src/tlf/simulate.py`); the files here
are the output of `python scripts/run_experiments.py` (seeds fixed, so they are reproducible) plus the public
Kaggle dataset used only for comparison.

## events_train.csv, events_test.csv, events_unseen.csv

One row per event (6,600 / 3,300 / 2,200 rows, 600 / 300 / 200 per class), 74 columns:

| columns | meaning |
|---|---|
| `event` | index within the set |
| `label` | the class: `none`, `AG`, `BG`, `CG`, `AB`, `BC`, `CA`, `ABG`, `BCG`, `CAG`, `ABC` |
| `kind`, `distance_km`, `r_arc`, `r_ground`, `inception_deg`, `load_step_mw`, `three_phase_grounded` | the fault specification: type, distance from the relay, arc resistance per faulted phase (Ω), ground resistance (Ω, ground faults only), phase-A voltage angle at the fault instant (°), load switched on at the fault point for `none` events (MW), whether an ABC fault also touches ground |
| `delta_deg`, `s_sc_mva`, `r_sc_mva`, `e_s_pu`, `e_r_pu`, `line_km` | the operating point: load angle, short-circuit levels of the local and remote source, source voltages, line length |
| `rf_total` | total fault resistance used for the resistance studies: `r_arc` + `r_ground` for ground faults, `r_arc` otherwise |
| `triggered` … `r_ca` (58 columns) | the relay features at the 1-cycle decision window, in per unit (see `src/tlf/features.py`): per-phase \|V\|, \|I\|, \|ΔI\|, \|ΔV\|, current rise ratio, share of the largest ΔI; sequence magnitudes and ratios; superimposed positive-sequence current; residual ratio; cos/sin of ∠(I₂/I₀), ∠(I₂/ΔI₁), ∠(I₀/ΔI₁); \|Z\|, X, R of the six distance-relay loops in per unit of the line impedance |

The features are computed after the record has been passed through the measurement model (random ±2 %
per-phase CT/VT ratio errors and white noise at 40 dB SNR), exactly as the relay would see it.

Reference system (train and test): 220 kV, 50 Hz, 100 km single-circuit line, R₁ = 0.07 Ω/km,
L₁ = 1.27 mH/km, C₁ = 9 nF/km, R₀ = 0.25 Ω/km, L₀ = 3.8 mH/km, C₀ = 5.5 nF/km; local source 5,000 MVA
(X/R 10), remote source 3,000 MVA (X/R 8); per event the load angle is drawn from 5–30°, the source strengths
within ±30 %, the source voltages from 0.97–1.05 and 0.95–1.03 pu. Unseen system: 150 km line, R₁ × 1.15,
L₁ × 0.85, C₁ × 1.1, R₀ × 0.85, L₀ × 1.15, sources 8,000 MVA (X/R 15) and 1,500 MVA (X/R 6), strengths
within ±20 %.

Random draws per event: distance 2–98 % of the line, arc resistance 10^U(−2, 0.7) = 0.01–5 Ω, ground
resistance 10^U(−1, 1.7) = 0.1–50 Ω, inception angle 0–360°; `none` events switch on either nothing or
20–150 MW of load at the fault point.

## waveforms_sample.npz

One raw record per class from the test set (the first event of each class), for the figures and the app:

| key | shape | meaning |
|---|---|---|
| `t` | (640,) | time in s, 4 kHz, 8 cycles (2 pre-fault + 6 post-fault) |
| `v`, `i` | (11, 640, 3) | phase voltages (V) and currents (A) at the relay, phases a, b, c |
| `labels`, `fault_index`, `distance_km`, `rf_total` | (11,) | class, sample index of the fault instant, distance, total fault resistance |

The CLI can run on such a record saved as CSV with columns `Va,Vb,Vc,Ia,Ib,Ic`.

## external/classData.csv — the Kaggle dataset (comparison only)

*Electrical fault detection and classification* (Kaggle, E. S. Prakash; a Simulink model of a transmission
line fed by generators at both ends), obtained from the GitHub mirror `Joiyad/fault-detection-and-classification-using-ML`
(no licence file in the mirror; the Kaggle page lists the dataset under its own terms, so it is **not
included in this repository** — download it from Kaggle and save it as `data/external/classData.csv`;
without it `scripts/run_experiments.py` skips §5). 7,861 rows, columns `G, C, B, A` (fault flags) and `Ia, Ib, Ic, Va, Vb, Vc`; every row is one time
sample, the file is six contiguous runs (one simulation per class) with no time column and an irregular
sample spacing. `scripts/run_experiments.py` §5 uses it to show why per-sample classification of such a
file cannot be compared with relay-style results (86.6 % / 88.2 % with a Random Forest, random vs
time-block split).
